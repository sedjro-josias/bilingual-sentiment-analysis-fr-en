# Bilingual Sentiment Analysis (French / English)

## Project Overview
This project involves the creation and analysis of a bilingual (French-English) text dataset for sentiment classification. It includes text preprocessing, labeling based on tone and intent, and a basic sentiment analysis pipeline.

The project builds on practical experience in text annotation, linguistic evaluation, and structured data labeling.

## Objectives
- Build a small bilingual dataset for sentiment analysis
- Preprocess text data (cleaning, tokenization, normalization)
- Perform sentiment classification
- Evaluate model performance and annotation consistency

## Tools & Technologies
- Python
- pandas
- scikit-learn
- nltk (or spaCy)
- matplotlib

## Key Steps
1. Collection / preparation of French and English texts
2. Manual labeling according to sentiment (Positive / Neutral / Negative)
3. Text preprocessing
4. Feature extraction (TF-IDF or simple bag-of-words)
5. Training of a baseline classification model
6. Performance evaluation and error analysis
